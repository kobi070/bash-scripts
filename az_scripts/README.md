# az_scripts

This repository contains shell scripts for managing and interacting with Microsoft Azure resources using the Azure CLI. These scripts are designed to simplify common Azure operations, including authentication and resource management.

## 📜 Scripts Overview

1. **az_script.sh**  
   A basic Azure CLI script for performing standard operations such as logging in, listing resources, or managing subscriptions.

2. **az_script_with_user.sh**  
   An Azure CLI script that includes user-specific configurations or prompts for user input during execution.

3. **az_script_advance.sh**  
   An advanced Azure CLI script that may include automation for resource provisioning, role assignments, or more complex workflows.

## 🚀 Usage

To run any of these scripts, use the following command in your terminal:

```bash
./script_name.sh
```

Replace script_name with the name of the script you want to execute (e.g., az_script, az_script_with_user, etc.).

✅ Prerequisites

- Azure CLI must be installed and configured on your system.
- You must be logged in to your Azure account (az login).
- Sufficient permissions to perform the operations defined in the scripts.
📘 Notes
- Review each script before running to ensure it aligns with your Azure environment and security policies.
- For more information on Azure CLI commands, visit the official documentation.
